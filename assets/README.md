# Project Assets

This folder contains media assets used in the `README.md` documentation:

- `banner.png`: Repository banner header (designed for dark and light GitHub themes).
- `demo.gif`: Terminal recording of NanoAgent executing autonomous loops with Rich UI.
- `architecture.png`: High-resolution architectural diagram of the ReAct engine and MCP capability layer.

To record terminal sessions into crisp GIFs, we recommend using [vhs](https://github.com/charmbracelet/vhs).
